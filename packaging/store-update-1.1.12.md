# Microsoft Store release notes for version 1.1.12.0

The "What's new in this version" field in each language: this paragraph first, then the 1.1.11.0 paragraph from `packaging/store-update-1.1.11.md`, separated by a blank line. Only what the Store build has.

## en-US

New: the first start after an update no longer stops on the loading bar. The dashboard's text is now drawn by one small shader instead of hundreds of copies of the same code, so the graphics driver prepares it in under two seconds instead of most of a minute, and the first start reaches the demo in about half the time. Drawing the dashboard also takes about half the GPU time, and it looks the same. When you close the app, the sound and the window now go at once. At the end the music now fades out, and a Play again button starts over from the beginning.

## zh-TW

新功能：更新後第一次啟動時，載入條不再停住。儀表板上的文字現在由一個小型著色器繪製，而不是同一段程式碼的數百份副本，因此顯示卡驅動程式準備它只需不到兩秒，而不是將近一分鐘，第一次啟動到演示開始的時間也縮短約一半。繪製儀表板也只需約一半的 GPU 時間，外觀完全相同。關閉應用程式時，聲音和視窗現在會立即消失。播放結束時，音樂現在會漸漸淡出，並出現「再看一遍」按鈕，可從頭再看一次。

## zh-CN

新功能：更新后首次启动时，加载条不再停住。仪表板上的文字现在由一个小型着色器绘制，而不是同一段代码的数百份副本，因此显卡驱动程序准备它只需不到两秒，而不是将近一分钟，首次启动到演示开始的时间也缩短约一半。绘制仪表板也只需约一半的 GPU 时间，外观完全相同。关闭应用时，声音和窗口现在会立即消失。播放结束时，音乐现在会渐渐淡出，并出现“再看一遍”按钮，可从头再看一次。

## ja-JP

新機能：アップデート後の初回起動で、読み込みバーが止まらなくなりました。ダッシュボードの文字を、同じコードを何百も複製する代わりに 1 つの小さなシェーダーで描画するようにしたため、グラフィックス ドライバーの準備は 1 分近くかかっていたのが 2 秒未満で済み、初回起動からデモが始まるまでの時間もおよそ半分になりました。ダッシュボードの描画にかかる GPU 時間もおよそ半分になり、見た目は変わりません。アプリを閉じると、音とウィンドウがすぐに消えるようになりました。最後に音楽がフェードアウトするようになり、「もう一度再生」ボタンで最初から見直せます。

## ko-KR

새 기능: 업데이트 후 첫 실행에서 로딩 바가 더 이상 멈추지 않습니다. 대시보드의 글자를 같은 코드의 수백 개 사본 대신 작은 셰이더 하나로 그리게 되어, 그래픽 드라이버가 이를 준비하는 데 1분 가까이 걸리던 것이 2초도 걸리지 않으며, 첫 실행에서 데모가 시작되기까지의 시간도 약 절반으로 줄었습니다. 대시보드를 그리는 데 드는 GPU 시간도 약 절반이며, 모양은 그대로입니다. 앱을 닫으면 이제 소리와 창이 바로 사라집니다. 이제 끝에서 음악이 서서히 잦아들고, '다시 보기' 버튼으로 처음부터 다시 볼 수 있습니다.
