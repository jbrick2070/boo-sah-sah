# Microsoft Store release notes for version 1.1.6.0

Appended as a second paragraph after the 1.1.5.0 notes (`packaging/store-update-1.1.5.md`) in each language's "What's new in this version" field, because 1.1.5.0 never shipped on its own. The dashboard button is named instead of the backtick key, because that key sits in a different place on non-US keyboards.

## en-US

New: press Shift+N to turn on neural rendering. Three small neural networks grade the picture, rebuild a compressed texture and learn the scene's lighting live on your GPU, and the dashboard shows each one's timing. The [-] button shrinks the dashboard to one strip or hides it.
