# Microsoft Store release notes for 2.2.0.0

The "What's new" field for each language (1,500 characters at most). 2.1.1 was never published on its own, so paste the 2.2 paragraph below, then the 2.1.1 paragraph from store-update-2.1.1.md.

## en-US

New in the benchmark: a Render test that path traces one frame of the orchid tile by tile while you watch, and a Film tour that measures six scenes from the film one by one. The benchmark window has a cleaner dark Windows 11 look, a description for each test and a real progress bar.

## zh-TW

基準測試新增：「渲染測試」讓你看著蘭花的一個畫面逐塊以路徑追蹤算出；「影片巡覽」逐一測量影片中的六個場景。基準測試視窗改為更簡潔的深色 Windows 11 外觀，每項測試附說明，並有真正的進度列。

## zh-CN

## ja-JP

ベンチマークに新機能：ランの 1 フレームをタイルごとにパストレーシングする様子を見られる「レンダーテスト」と、映画の 6 シーンを 1 つずつ計測する「フィルムツアー」。ベンチマーク画面はすっきりしたダークな Windows 11 の見た目になり、各テストの説明と本物の進行状況バーが付きました。

## ko-KR
