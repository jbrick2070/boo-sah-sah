# Hardware controls and Windows release checks

The five engine rows open comparisons at the current film position. Key 4 opens the guided sanctuary scene. Tab, closing the comparison, selecting another engine and explicit navigation leave the guide. The sample, pause state and loop are restored before applying a newly selected destination. The user’s NPU preference applies across those transitions.

A scripted test sent real window messages to a private Windows desktop on the RTX 5080 Laptop GPU. It verified 33 actions, including the click targets in landscape and portrait, switches between all five comparison tabs, restoration of the paused playhead, a scrub out of the guide, advancing to the next act, the NPU preference and the Traditional Chinese credit dialog. The shrine and film clocks were read from the running application window. Native hardware integration passed all 19 cases, and the public unit suite passed 25 cases.

The soundtrack waits while graphics start. If the opening recording is still decoding, WASAPI receives silence with a zero-length film interval. The film and the song then start from the same opening sample. A Windows test held an opening recording with a filesystem oplock. After 1.1 seconds, the timeline still reported zero samples. It advanced past 9,600 samples when file access resumed.

The ray-traced sky pass rejects covered pixels before casting rays. Across twelve 1440p frames, twelve 4K frames and two 1440p street-level frames on the personal release candidate, the native 10-bit output matched the same frames without early depth testing. The separate public film measurements are in the preceding phase. [Film measurements](../city-phase5/README.md)

The MSIX verifier checks all runtime languages, the package identity, the compiled shaders and the registered media. Store builds can require the OpenVINO and NRD sidecars, their runtime components and their license notices with the following switch.

```powershell
.\packaging\msix\make-msix.ps1 -IdentityName $name -Publisher $publisher -PublisherDisplay $display -Version $version -RequireHardwareSidecars
```

Local certification with WACK requires an elevated Windows session. Physical 8 GB RTX 4060 performance and native 4K presentation at 60 fps remain open.
